# Remote-Sensing-Project-Frery-Doumbia-

This is the page of the project of the creation of a model of detection of the fire of Gironde in 2026 using Remote Sensing , Statistics , Machine and Deep Learning algorithms for classification and prediction 

The folder "data"   contains all unprocessed master data and processed data , with Indices (NDVI) , ratio (CTVI) , color composites , statistical processing (Principal Component Analysis (PCA) , Minimum Noise Fraction (MNF)) , Models of Unsupervised (K-Means , Isoclust , K-Nearest Neigbhors (KNN)
